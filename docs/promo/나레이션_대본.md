## 2. ElevenLabs에 넣을 텍스트

### 방법 A · 한 번에 만들기 (추천: 톤이 일정해요)
아래 전체를 Text to Speech 입력창에 그대로 붙여 넣으세요. 문장 사이 줄바꿈과 "..."이 쉬는 구간이 되고, 받은 파일은 제가 문장별로 잘라서 맞춰요.

```
에이아이 쓸 때마다, 창을 옮겨 다니나요?
...
쓸 에이아이만, 장바구니처럼 쏙!
...
한 대화창에서, 알맞은 에이아이가 자동으로.
...
남은 만큼 한눈에, 매주 새로 충전.
...
쓸 에이아이만 골라 담고, 고르는 건 시엠프레가 할게요.
```

### 방법 B · 문장별로 만들기
한 문장씩 따로 생성해서 `e1.mp3` ~ `e5.mp3`로 저장해 주세요. 마음에 안 드는 문장만 다시 뽑기 편해요.

### Eleven v3 모델을 쓸 경우 (감정 태그 버전)
v3는 대괄호 태그로 말투를 줄 수 있어요. Multilingual v2에서는 태그를 넣지 마세요(태그를 소리 내어 읽어요).

```
[curious] 에이아이 쓸 때마다, 창을 옮겨 다니나요?
[cheerful] 쓸 에이아이만, 장바구니처럼 쏙!
[confident] 한 대화창에서, 알맞은 에이아이가 자동으로.
[friendly] 남은 만큼 한눈에, 매주 새로 충전.
[warm] 쓸 에이아이만 골라 담고, 고르는 건 시엠프레가 할게요.
```
