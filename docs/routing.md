# 라우팅 규칙

요청을 아래 유형 중 하나로 나누고, 그 유형의 기본 모델로 보낸다. 기본 모델이 실패하거나 사용자가 그 AI를 담지 않았으면 대체 모델을 쓴다.
코드의 값은 `app/src/config/routing.ts`, 분류 로직은 `app/src/lib/router.ts`.

| 요청 유형 (id) | 기본 모델 | 대체 모델 | 차감 크레딧 |
| --- | --- | --- | --- |
| 가벼운 대화 (`light`) | Mistral Small 4 | Qwen3.7-Plus | 0 (하루 300회) |
| 요약·번역 (`translate`) | Qwen3.7-Plus | Mistral Small 4 | 1 |
| 가성비 고난도 (`bulk`) | Mistral Large 3 | Qwen3.7-Max | 2 |
| 글쓰기·일반 질문 (`write`) | Claude Sonnet 5.5 | Qwen3.7-Plus | 5 |
| 고난도 추론·코딩 (`hard`) | Claude Opus 5.5 | Qwen3.7-Max | 19 |
| 음성 생성 (`voice`) | ElevenLabs Multilingual | — | 1,000자당 30 |
| 이미지 생성 (`image`) | Nano Banana 2.1 | — | 1장당 11 (2K 16) |

- 1크레딧은 약 ₩9 가치다 (주간 크레딧 = 월 결제액 ÷ 36).
- 음성·이미지 차감량은 API 단가에서 계산한 값이며 PRD 확정이 필요하다.

## 화면에서 지킬 것

1. 답변마다 **모델 칩 + 고른 이유 + 차감 크레딧**을 보여 준다. 예: "Claude Sonnet 5.5 · 글쓰기 요청이라 자동 선택 · 5크레딧"
2. 보내기 전에 입력창에 **예상 유형과 크레딧**을 보여 준다.
3. **다른 모델로 다시 받기**: 자동으로 고른 답이 마음에 안 들어 다시 받으면 첫 답의 크레딧을 돌려준다.
4. **더 꼼꼼하게** 토글을 켜면 한 단계 위 유형(`write` → `hard`)으로 보낸다.
5. 사용자가 **담지 않은 AI가 필요한 요청**(예: 음성인데 ElevenLabs 안 씀)이면 답 대신 안내 카드를 보여 준다: [이번만 크레딧으로 쓰기] / [구독에 담기].
6. 모델이 바뀌어도 앞 대화를 함께 보내서 맥락을 잇는다. 이미지 요청은 앞 대화에서 주제만 요약해 넣는다.

## 비용 안전장치

- 요청 1건 원가가 ₩500을 넘으면 더 저렴한 모델로 다시 보낸다.
- 사용자 1명 하루 원가가 ₩3,000을 넘으면 관리자에게 알린다.
