# **Siempre SWOT 분석**

2026년 11월 5일 ·

## **한눈에 보기**

Siempre는 요청마다 알맞은 AI(Claude, Qwen, Mistral)를 자동으로 골라 한 대화에서 작업을 끝내 주는 서비스입니다. 가장 큰 강점은 **자동 라우팅**이고, 가장 큰 위협은 **무료로 여러 AI를 제공하는 뤼튼**과 **공급사 의존**입니다.

성패는 사용자가 자동 라우팅을 믿느냐에 달려 있습니다.

## **SWOT**

### **강점 (S) · 내부, 도움이 되는 요인**

* **자동 라우팅**: 사용자가 모델을 고를 필요 없이 요청마다 알맞은 모델로 보냅니다.  
* **한 대화에서 완결**: 글쓰기, 번역, 고난도 질문이 맥락을 이어 가며 한 대화에서 끝납니다.  
* **낮은 원가**: Mistral·Qwen처럼 원가가 매우 싼 모델로 가벼운 대화를 무제한 제공할 수 있습니다.  
* **장바구니식 구독**: 쓰는 AI만 골라 담아 그만큼만 냅니다.  
* **미사용분 수익**: 주간 크레딧과 이월 제한으로 쓰지 않은 크레딧이 수익이 됩니다.

### **약점 (W) · 내부, 걸림돌이 되는 요인**

* **공급사 의존**: 자체 모델이 없어 공급사의 가격·정책 변화에 그대로 노출됩니다.  
* **라우팅 실수의 책임**: 라우팅이 틀리면 품질 불만이 바로 서비스 탓이 됩니다.  
* **가벼운 모델로 보내 결과가 부족할 수 있음**: 사용자는 다시 시켜야 하고, 크레딧과 시간을 낭비했다고 느낍니다.  
* **이미지·음성 생성 없음**: 현재 구성(Claude, Qwen, Mistral)에는 이미지·음성 모델이 없습니다.  
* **인지도 0**: 브랜드가 알려지지 않아 마케팅 예산이 필요합니다.  
* **크레딧 소멸 불만**: 사라지는 크레딧 때문에 불만과 환불 분쟁이 생길 수 있습니다.

### **기회 (O) · 외부, 도움이 되는 요인**

* **빠르게 크는 시장**: 한국 생성형 AI 사용률 40.6%, 1년 새 약 15%p 상승했습니다.  
* **돈을 내는 사용자 증가**: 유료 결제율 25.9%, 유료 이용자는 월 평균 ₩35,932를 씁니다.  
* **여러 AI를 함께 결제하는 사람**: 유료 이용자 중 최소 11.9%가 두 개 이상 결제합니다(핵심 타깃 약 117만 명, 자체 추정).  
* **내려가는 모델 가격**: 모델 가격이 계속 내려가 원가를 개선할 여지가 있습니다.  
* **여러 AI를 쓰는 직군 증가**: 1인 크리에이터, 마케터처럼 여러 AI를 동시에 쓰는 사람이 늘고 있습니다.

### **위협 (T) · 외부, 걸림돌이 되는 요인**

* **무료 경쟁자**: 뤼튼이 여러 AI를 무료로 제공하며 월 사용자 1,000만 명에 가깝습니다.  
* **대형 AI 앱의 확장**: ChatGPT, Claude, Gemini가 자체 앱 기능을 넓혀 "한 곳에서 다 됨"을 직접 제공합니다.  
* **공급사가 모델을 갑자기 바꾸거나 없앰**: 같은 요금을 냈는데 결과가 나빠졌다고 느끼고, 우리 서비스 탓으로 받아들입니다.  
* **남의 모델인데 책임은 우리에게**: 틀린 답, 불쾌한 표현, 이유 없는 거절이 나와도 사용자는 우리에게 항의합니다. 평판과 법적 책임으로 이어질 수 있습니다.  
* **약관·가격 변경**: 공급사가 재판매나 용도를 제한하거나 가격을 올릴 수 있습니다.  
* **국내 규제**: 개인정보 국외 이전 동의, 선불 크레딧 환불 규정을 지켜야 합니다.  
* **공급사 장애**: 공급사에 장애가 나면 서비스 품질이 함께 떨어집니다.

## **전략으로 연결**

| 전략 | 무엇을 할까 |
| ----- | ----- |
| **SO** · 강점으로 기회 잡기 | 여러 AI를 결제 중인 사람을 정면으로 공략합니다. "AI 구독 여러 개 대신 하나로, 고르는 수고 없이"를 내세우고, 가입 화면에서 지금 내는 구독료와 비교한 절약액을 보여줍니다. |
| **WO** · 약점을 기회로 보완 | 모델 가격이 내려가는 흐름에 맞춰 라우팅 규칙을 계속 저렴한 모델 쪽으로 조정합니다. 이미지 모델은 수요를 확인한 뒤 하나만 추가합니다. |
| **ST** · 강점으로 위협 막기 | 뤼튼과는 "모델 모음"이 아니라 "자동으로 골라 주기 \+ 한 대화에서 끝나는 작업"으로 차별화합니다. 공급사 장애에는 대체 모델로 자동 전환합니다. |
| **WT** · 약점과 위협이 겹치는 곳 방어 | 모델을 최소 3개 회사로 나눠 특정 공급사 의존을 줄입니다. 크레딧 소멸 규칙은 결제 화면과 약관에 분명히 표시하고, 출시 전 API 약관과 개인정보 국외 이전 동의를 법률 검토받습니다. |

## **추가 위험과 보완 방안**

| 위험 | 보완 방안 |
| ----- | ----- |
| **공급사가 모델을 바꿔 품질이 떨어짐** | 날짜가 붙은 고정 버전을 쓰고, 새 버전은 평가 세트로 먼저 시험한 뒤 전환합니다. 바꿀 때는 7일 전에 공지합니다. 구독 상품은 특정 모델이 아니라 "성능 등급"(라이트·스탠다드·헤비)으로 약속합니다. |
| **가벼운 모델로 보내 일을 덜 함** | 보내기 전에 어떤 모델이 답할지 보여주고 "더 꼼꼼하게" 버튼으로 상위 모델을 고르게 합니다. 자동으로 고른 답이 마음에 안 들어 다시 받으면 첫 답의 크레딧을 돌려줍니다. 답이 짧거나 끊기면 상위 모델로 자동 재요청합니다. |
| **불쾌한 답변의 책임이 우리에게 옴** | 답변마다 어떤 모델이 답했는지 표시하고, 우리 쪽 안전 필터를 한 겹 더 둡니다. 신고 버튼을 두고 신고된 답변은 크레딧을 돌려줍니다. 의료·법률·금융 질문에는 안내 문구를 붙이고, 책임 범위를 약관에 명시합니다. |

크레딧 환급과 자동 재요청은 원가를 늘리므로, "다른 모델로 다시 받기" 비율을 10% 이하로 유지해 추가 원가를 전체 API 원가의 약 10% 안으로 묶습니다.

## **가장 중요한 한 가지**

이 서비스의 성패는 **사용자가 자동 라우팅을 믿느냐**에 달려 있습니다. 강점의 대부분이 여기서 나오고, 뤼튼과의 차별점도 여기에 있습니다.

그래서 베타에서는 "다른 모델로 다시 받기" 비율(목표 10% 이하)을 가장 먼저 봐야 합니다.

지금 생성형 AI 시장은 빠르게 커지고 있습니다. 사용률은 1년 만에 약 15%포인트 올랐고, AI에 돈을 내는 사람도 네 명 중 한 명꼴입니다. 특히 눈여겨볼 점은, 유료 이용자 중 최소 열 명에 한 명은 AI를 두 개 이상 결제해서 쓰고 있다는 것입니다.

하지만 경쟁도 만만치 않습니다. 여러 AI를 무료로 한곳에 모은 뤼튼이 이미 자리를 잡았고, ChatGPT, Claude, Gemini도 자기 앱 안에서 할 수 있는 일을 계속 늘리고 있습니다.

그래서 저희는 두 가지를 무기로 삼습니다. 첫째, 요청할 때마다 가장 알맞은 AI를 자동으로 골라 주고, 한 대화 안에서 일을 끝낼 수 있게 하는 기능입니다. 둘째, 실제로 쓰는 AI만 골라 담아 그만큼만 내는 크레딧 구독입니다.

처음 공략할 대상은 여러 AI를 번갈아 쓰는 1인 크리에이터와 마케터입니다. 다른 서비스가 AI를 "모아 두는" 데 그친다면, 저희는 "알아서 골라 준다"는 점으로 차별화합니다. 그리고 두 달 이상 꾸준히 쓴 사용자에게는 연간 구독 할인을 제안해, 오래 머무는 고객으로 만들겠습니다.


**Statement**
>
여러 AI를 동시에 결제하는 사람이 늘고 무료 통합 서비스와 빅테크 앱의 경쟁이 거센 시장에서, 우리는 자동 라우팅과 골라 담는 크레딧 구독으로 1인 크리에이터·마케터에게 '모아 두기'가 아닌 '자동으로 골라 주기'를 제공하는 집중 차별화 전략을 택한다.
