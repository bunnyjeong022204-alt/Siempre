# 작업 의도: 로그인과 서비스 화면 연결

- 작성일 / 실제 변경 기간(KST): 2026-11-09
- 상태: 구현·로컬 검증 (PR 미승인)
- 담당: 김형민 (회원가입·로그인). 연결 대상 화면 담당: 권희수
- 이전 기록: [20261109-signup-flow](../20261109-signup-flow/intent.md)

## 문제와 기대 효과

- 회원가입·로그인(React, `frontend/index.html`)과 권희수 님의 서비스 화면(`frontend/siempre-figma-prototype.html`, 구독·대화·크레딧)이 따로 있었다. 서비스 화면에는 로그인 확인이 없고 사용자 이름이 "도윤 님"으로 고정돼 있었다.
- PRD 5-0 "로그인하지 않은 사용자가 구독·대화·크레딧 화면에 들어오면 로그인 화면으로 보낸다"를 서비스 화면에도 적용한다.

## 범위와 비목표

- **범위:** 로그인·가입 후 서비스 화면으로 이동, 서비스 화면의 로그인 확인·닉네임 표시·로그아웃.
- **비목표:** 구독·결제·크레딧 데이터를 회원 계정에 저장하기 (권희수 님 `subscription`·`credits` 파트), 서비스 화면 디자인 변경.

## 결정

- frontend/README.md 규칙("서로 남의 화면 파일은 고치지 않아요")을 지키려고, 서비스 화면 HTML에는 연결 스크립트를 부르는 `<script>` **한 줄만** 넣고 나머지는 김형민 파일(`src/bridge/prototypeAuth.ts`)에 둔다. 요청자 선택(추천 방식).
- 그 한 줄도 권희수 님 파일 변경이라 PR에 명시하고 확인을 받는다.
