# SPEC — 무엇이 만들어지면 완료인지

> MVP 완료를 판단하는 기준이다. 기능의 자세한 요구사항은 [`../PRD.md`](../PRD.md) 5장, API 형식은 [`../../backend/`](../../backend/) 파트별 README를 따른다.
> 확정 2026-11-09

## 1. 한 문장 완료 기준

처음 온 사람이 **가입 → 로그인 → AI 담기 → 데모 결제 → 대화 → 크레딧 확인**을 처음부터 끝까지 막힘없이 할 수 있으면 MVP 완료다.

## 2. 화면별 완료 조건

### 2-1. 회원가입·로그인 (김형민)

- [ ] 이메일·닉네임·비밀번호·필수 약관 동의로 가입할 수 있다.
- [ ] 이메일·비밀번호로 로그인하고, 새로고침해도 로그인이 유지된다. 로그아웃할 수 있다.
- [ ] 로그인하지 않고 구독·대화·크레딧 화면에 들어가면 로그인 화면으로 이동한다.
- [ ] 이미 가입된 이메일로 가입하려 하면 오류로 막지 않고 로그인 화면으로 안내한다.
- [ ] 비밀번호 칸은 가려진 상태로 시작한다.

### 2-2. 구독 선택 (곽희수)

- [ ] AI마다 라이트·스탠다드·헤비 중 하나를 고르거나 담지 않을 수 있다.
- [ ] 고를 때마다 장바구니 항목, 묶음 할인, 월 결제액, 주간 크레딧이 바로 바뀐다.
- [ ] PRD 3-4 예시 구성(GPT 스탠다드 + Qwen 라이트 + Mistral 스탠다드)이 **월 ₩23,670**으로 나온다.
- [ ] AI 카드마다 공식 구독 대비 절약액이 보인다.

### 2-3. 데모 결제 (곽희수)

- [ ] 결제 내용을 확인하고 결제하면 구독이 저장된다. 실제로 돈은 나가지 않는다.
- [ ] 결제 즉시 첫 주 크레딧이 채워지고, 다음 충전일이 결제한 요일로 정해진다.
- [ ] 결제 후 대화 화면으로 이동한다.

### 2-4. 대화 (곽희수)

- [ ] 요청을 보내면 PRD 4-2 표에 맞는 모델이 답한다. 기본 모델의 AI를 담지 않았으면 대체 모델이 답한다.
- [ ] 답변마다 모델 칩(모델별 색), 선택 이유, 차감 크레딧이 보인다.
- [ ] 보내기 전에 입력창 근처에 예상 요청 유형과 차감 크레딧이 보인다.
- [ ] "다른 모델로 다시 받기"로 같은 질문을 다른 모델에게 다시 받을 수 있다.
- [ ] 모델이 바뀌어도 앞 대화 맥락이 이어진다.
- [ ] 크레딧이 모자라면 답하지 않고 안내(추가 충전 또는 구성 변경)를 보여 준다.

### 2-5. 크레딧 (곽희수)

- [ ] 이번 주 남은 크레딧, 주간 지급량, 다음 충전일이 보인다.
- [ ] 내 구독 구성(AI별 단계, 월 결제액)이 보인다.
- [ ] 최근 기록(시간·작업·모델·크레딧)이 보인다.
- [ ] 추가 충전(데모) 버튼이 동작한다.

## 3. 기술 완료 조건

- [ ] AI 공급사 API 키가 프론트엔드 코드와 깃헙 어디에도 없다. 서버 `.env`에만 있다.
- [ ] 비밀번호는 해시로만 저장되고, 로그·주소·응답에 평문으로 남지 않는다.
- [ ] 모든 API가 [`backend/shared/README.md`](../../backend/shared/README.md) 2장의 응답·오류 형식을 따른다.
- [ ] `backend/` 파트별 README의 "끝났는지 확인" 체크리스트를 모두 통과한다.
- [ ] README에 적힌 명령만으로 다른 팀원이 자기 컴퓨터에서 실행할 수 있다.

## 4. 안 만드는 것 (MVP 범위 밖)

실제 결제, 소셜 로그인, 비밀번호 찾기 메일, 대화 검색, 설정 화면, 팀 요금제, 모바일 앱, 여러 모델 동시 비교 (PRD 8-1)

## 5. 완료 확인 방법

1. 새 계정으로 1장의 흐름을 처음부터 끝까지 한 번 진행한다.
2. 2·3장 체크리스트를 하나씩 확인하고, 통과하지 못한 항목은 이슈로 남긴다.
3. 모든 항목이 통과하면 PM이 MVP 완료를 선언한다.
