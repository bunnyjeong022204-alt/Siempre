# INTENT — 어떤 아이디어인지

> 이 문서는 "왜, 누구를 위해, 무엇을" 만드는지 정리한다. 세부 기능과 숫자는 [`../PRD.md`](../PRD.md)가 기준이다.
> 확정 2026-11-09

## 1. 한 줄

쓸 AI만 장바구니처럼 골라 담고, 한 대화창에서 요청마다 알맞은 AI가 자동으로 답하는 AI 통합 구독 서비스.

## 2. 왜 만드나

| 문제 | 지금 사용자가 겪는 일 |
| --- | --- |
| 여러 AI를 따로 구독하면 비싸다 | 글은 이 AI, 번역은 저 AI가 낫다고 해서 구독을 늘리다 보면 매달 수만 원이 나가는데, 정작 각 구독을 다 쓰지 못한다. |
| 어떤 AI가 좋은지 고르기 어렵다 | 요청마다 어느 AI·어느 모델이 맞는지 사용자가 직접 판단해야 하고, 잘못 고르면 결과가 나쁘거나 비싼 모델을 낭비한다. |
| 창을 오가며 같은 설명을 반복한다 | AI를 바꿀 때마다 새 창을 열고 앞에서 한 설명을 다시 붙여 넣어야 한다. |

## 3. 누구를 위해

- **타깃 사용자:** 글쓰기·번역·영상 대본 등 여러 AI를 섞어 쓰는 크리에이터, 대학생, 직장인
- **핵심 사용자:** 1인 유튜버
  - 대본 쓰기, 자막 번역, 아이디어 정리, 썸네일 문구처럼 성격이 다른 작업을 한 영상 안에서 모두 한다.
  - 혼자 작업해서 시간이 부족하고, 구독료에 민감하다.

## 4. 어떻게 해결하나

| 해결 방법 | 사용자가 얻는 것 |
| --- | --- |
| **AI마다 필요한 만큼만 담기** (라이트·스탠다드·헤비), 묶으면 할인 | 안 쓰는 AI에 돈을 내지 않고, 여러 개를 담을수록 싸진다. |
| **요청 자동 분류 → 알맞은 모델로 전송**, 답변마다 모델·이유·차감 크레딧 표시 | AI를 고르는 고민이 사라지고, 한 대화창에서 맥락이 이어진다. |
| **크레딧은 매주 결제일 기준 요일에 지급, 이월 없음** | 한 주 단위로 사용량을 가늠하기 쉽다. 남은 크레딧이 쌓이지 않아 가격을 낮게 유지할 수 있다. |

## 5. 우리만의 매력

1. **자동 라우팅 + 쓰는 만큼 내는 구조:** 비슷한 서비스는 여러 AI를 모아 두기만 한다. 우리는 요청에 맞는 모델을 대신 골라 주고, 담은 만큼만 낸다.
2. **"왜 이 모델인지" 보여 주기:** 답변마다 "글쓰기 요청이라 자동 선택 · 5크레딧"처럼 이유와 비용을 보여 줘서 자동 선택을 믿고 쓸 수 있다. 마음에 안 들면 다른 모델로 다시 받을 수 있다.

## 6. 이 아이디어가 맞는지 확인하는 방법

PRD 7-1의 베타 지표로 확인한다.

| 확인하려는 것 | 지표 |
| --- | --- |
| 자동 라우팅을 믿는가 | 다른 모델로 다시 받기 비율 10% 이하 |
| 계속 쓰는가 | 4주 차 재방문율 30% 이상 |
| 돈을 낼 만한가 | 무료→유료 전환율 5% |
| 수익 구조가 맞는가 | 크레딧 사용률 50~70% |
