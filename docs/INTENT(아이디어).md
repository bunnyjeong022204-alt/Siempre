# INTENT

## 한 줄
쓸 AI만 장바구니처럼 골라 담고, 한 대화창에서 요청마다 알맞은 AI가 자동으로 답하는 AI 통합 구독 서비스.

## 왜 만드나
- AI를 여러 개 따로 구독하면 비싸고, 다 쓰지도 못한다.
- 요청마다 어떤 AI가 좋은지 사용자가 고르기 어렵다.
- 창을 여러 개 오가며 같은 설명을 반복해야 한다.

## 누구를 위해
- 글쓰기·번역·영상 대본 등 여러 AI를 섞어 쓰는 크리에이터, 대학생, 직장인
- 핵심 사용자: 1인 유튜버

## 어떻게 해결하나
- AI마다 필요한 만큼만 담기 (라이트·스탠다드·헤비), 묶으면서 할인
- 요청을 자동 분류해 알맞은 모델로 보내고, 모델·이유·차감 크레딧을 보여 줌
- 크레딧은 매주 결제일 기준 요일에 지급, 이월 없음

## 우리만의 매력
- 자동 라우팅 + 쓰는 만큼 내는 구조
- 답변마다 "왜 이 모델인지" 보여 줘서 믿고 쓸 수 있음
