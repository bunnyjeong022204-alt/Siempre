## 문제와 기대 효과

- 지금 앱은 구독 선택·대화·크레딧만 있고 가입 단계가 없다. 시연에서 "처음 온 사람이 가입하고 구독 구성으로 넘어가는" 흐름을 보여 줄 수 없다.
- 요청자는 Figma `확정용` 페이지의 회원가입 시안을 디자인 명세 토큰과 Pretendard 글꼴로 맞추고, 프런트·백엔드를 CLAUDE.md 구조로 구현하길 원했다.
- 성공 판단: 5단계(가입 방식 → 본인 인증 → 계정 정보 → 약관 동의 → 완료)를 실제 API로 끝까지 진행할 수 있고, 잘못된 입력은 화면과 서버 양쪽에서 막힌다. 근거는 [plan.md](plan.md)의 검증 기록.

## 범위와 비목표

**범위**
- `app/`: `/signup` 아래 5개 화면, 회원가입 전용 컴포넌트, `config/signup.ts`, `lib/signup.ts`, `api/signup.ts`, `state/SignupState.tsx`
- `server/`: 새 폴더. 외부 패키지 없이 Node 내장 `http` + `node:sqlite`로 만든 회원가입 API와 테스트
- 소개 패널 수정: 카드 줄맞춤·색 통일, 큰 화면에서 360px 고정
- 간편가입(구글·카카오·네이버) 로고와 OAuth 가입 흐름 (키가 없으면 시연 모드)
- Figma `확정용 > 회원가입 시안` 섹션을 같은 기준으로 갱신

**비목표**
- 로그인·세션·비밀번호 찾기·탈퇴 처리 (가입만 먼저 만든다)
- 실제 문자 발송 연동 (없으면 시연 모드로 인증번호를 화면에 보여 줌)
- 추천인 입력, 주소 입력 (Siempre 기획에 없음)
- 기존 화면(구독 선택·대화·크레딧) 변경

**선택한 대안**
- 백엔드: Node 내장 기능 + SQLite (요청자 선택). Python 표준 라이브러리안은 팀 스택(Node)과 달라서 제외.
- 기준 브랜치: `app-structure` (CLAUDE.md와 `app/` 구조가 `main`에는 아직 없음, 요청자 선택).
