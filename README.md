# Siempre

쓸 AI만 골라 담고, 한 대화에서 요청마다 알맞은 AI가 자동으로 답하는 AI 통합 구독 서비스.

## 바로 시작하기

```bash
cd app
npm install
npm run dev   # http://localhost:5173
```

AI 코딩 도구로 작업한다면 [`CLAUDE.md`](CLAUDE.md)를 먼저 읽게 해 주세요. 폴더 구조, 규칙, 작업 순서가 모두 들어 있습니다.
