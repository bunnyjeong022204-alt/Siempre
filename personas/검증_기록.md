# 페르소나 자료 반영 전 점검

점검일: 2026-11-09

## 변경 범위

- 기존 README에 PRD·페르소나·조사 자료 링크를 추가한다.
- `personas/`에 상세 페르소나, 조사 엑셀 원본, 출처 메타데이터, 이 기록을 추가한다.
- 기존 PRD·시나리오·웹 코드는 변경하지 않는다. 기존 김도윤 페르소나를 유지하고 최신 PRD와 연결한다.
- `code.js`는 미제공이며 사용자와 합의한 자료 중심 범위에 따라 제외한다. 해당 파일을 참조하는 `manifest.json`도 제외한다.
- 약 1.98GB의 Parquet 원문은 업로드하지 않는다. 로컬 파일 9개의 행 수·열 구조를 확인하고 직업 관련 열을 순회했다. 이름·가족·주거·건강 관련 원문은 재배포하지 않는다.

## 충돌과 내용 일관성

반영 기준 main 커밋은 `aa5d81742874118852969253d9db86f2445b13e6`이다. 작업 중 추가된 `교시별 진행일정.md`를 포함한 최신 트리를 보존한다. 이 트리에는 `personas/` 경로가 없고 README 원문은 `# Siempre` 한 줄이다. PRD의 blob SHA도 이전 점검과 같음을 확인했다. main 갱신은 기대한 커밋과 일치할 때만 수행한다.

기존 시나리오는 GPT·Midjourney와 임시 차감량을 사용하지만 최신 PRD03은 Claude·Nano Banana를 지정한다. 새 페르소나는 PRD03을 기준으로 하고 옛 문서를 임의 수정하지 않았다. 무료 사용량·텍스트 사용량 기간·차감량의 미확정 상태를 유지했다. 로그인·실제 결제·팀 기능·병렬 모델 비교·자동 다단계 작업을 MVP 기능으로 약속하지 않았다.

## 첨부 엑셀 검사

원본과 업로드용 복사본의 SHA-256은 `persona_sources.json`에 기록한다. ZIP 내부 CRC 검사에서 손상을 발견하지 않았다. 1개 시트, 헤더 제외 8개 사례, 수식 0개다. VBA·외부 통합문서 링크·임베디드 개체는 발견하지 않았다. 외부 관계는 공개 출처로 연결되는 HTTPS 하이퍼링크 8개이며 자동 실행하지 않았다. 실명·소속·날짜·출처·서식은 원본 그대로 보존한다. 내용을 바꾸지 않아 재계산이나 서식 변경은 수행하지 않았다.

## 보안과 출처 처리

반영할 텍스트와 엑셀 문자열에서 일반적인 API 키·개인키·토큰 패턴을 확인한다. 공급사 키, 로컬 경로, 실행 코드, 대용량 원문은 추가하지 않는다. 첨부 문서와 데이터의 텍스트는 참고자료로만 읽었으며 그 안의 지시를 실행하지 않았다. 이 검사는 정적 자료 범위이며 웹 서비스 전체 보안 감사가 아니다.

공개 사례의 실명은 출처 추적을 위해 원본에 유지하고 한국어 이름은 가상 페르소나에만 적용했다. 외부 기사의 사실관계는 재검증하지 않았고, Parquet의 생성 방식·라이선스도 확인되지 않았다. 데이터가 실제 AI 사용이나 대표성을 증명한다고 주장하지 않는다.

## 반영 후 확인 방법

main의 최종 커밋, 변경 파일 목록, 각 파일의 Git blob SHA를 작성한 내용과 대조한다. 기존 파일에 의도하지 않은 변경이 없는지 비교한다. 웹 코드를 수정하지 않으므로 웹 테스트 대신 자료의 구조·경로·무결성과 원격 반영 상태를 검증한다. 커밋과 원격 검증 결과는 작업 완료 보고에서 제공한다.
