## 근거와 읽는 방법

함께 보기: [공개 사례 조사 원본](멀티%20AI%20사용%20사용자%20사례%20조사.xlsx) · [데이터 출처와 채택 레코드](persona_sources.json) · [반영 전 점검 기록](검증_기록.md).

기준 문서는 [Siempre MVP PRD](../PRD/Siempre_MVP_PRD.md) PRD03이다. 기존 [유튜버 시나리오](../Siempre%20유튜버%20사용%20시나리오%20%C2%B7%20MVP%20화면%20범위%20(%EC%B4%88%EC%95%88).md)에 김도윤의 배경과 작업 방식이 있어 이를 유지·확장했다. 시나리오의 GPT·Midjourney 및 임시 차감량보다 최신 PRD의 Claude·Nano Banana와 기능 범위를 우선한다. 이 문서는 제품 요구사항을 새로 확정하지 않는다.

첨부 조사 엑셀은 공개 인물의 다중 AI 활용 사례를 모은 참고자료다. 출처 URL과 원래 이름을 보존했으며 이번 작업에서 외부 기사 내용을 재검증하지 않았다. 엑셀의 ‘확인 수준’은 원본 작성자의 평가다. 공개 사례의 도구 조합을 Siempre의 지원 기능으로 해석하면 안 된다.

제공된 한국 페르소나 Parquet 9개 파일은 26개 열, 합계 1,000,000개 행이다. 직업·업무 설명을 탐색했으며, 직업 맥락이 명확한 일부 레코드만 배경 설계에 참고했다. 키워드 탐색은 대표 표본 추출이 아니며 이 데이터로 실제 AI 이용률이나 유료 전환율을 추정하지 않는다. 데이터의 생성 방식과 배포 라이선스는 로컬 파일만으로 확인되지 않아 원문 데이터·장문 인용은 저장소에 재배포하지 않았다.

아래 인물은 모두 가상이다. 이름·나이·도구 사용·예산·목표는 기존 PRD에 있는 사실을 제외하면 기획상 설정이다. 데이터 레코드의 인물이 실제로 해당 AI를 쓴다고 주장하지 않는다. 개인의 건강·가족·소득·성격 묘사는 제품 필요와 관계가 없어 옮기지 않았다.

## P01 김도윤 — 혼자 영상을 완성하는 유튜버

**배경:** 기존 PRD의 생활 경제 채널 운영자. 구독자 3만 명, 주 2회 업로드하며 얼굴 없는 자료 화면과 AI 내레이션을 활용한다. 기획·대본·편집을 혼자 맡는다. 기존 문서의 월 약 55,000원은 당시 시안상의 도구 비용 예시이며 현재 공식 가격을 뜻하지 않는다.

**현재 흐름:** ChatGPT에서 대본을 작성하고 ElevenLabs에 붙여 넣은 뒤 Midjourney에 썸네일 주제를 다시 설명한다. 대본 수정 후 음성·이미지에 옛 내용이 남는 것이 가장 큰 부담이다.

**해야 할 일:** 금요일까지 8분 영상의 대본, 내레이션 MP3, 썸네일 후보 3장을 준비한다. 같은 주제·숫자·표현이 모든 산출물에 일관되게 남아야 한다.

**Siempre 흐름:** Claude·ElevenLabs·Nano Banana를 담고 대본 작성, 도입부 수정, 확정 대본 음성화, 같은 영상 썸네일 생성을 한 대화에서 순서대로 요청한다. 자동 다단계 에이전트 실행과 영상 편집·자막 생성은 MVP 범위가 아니다.

**선택 기준과 막힘:** 작업 전 예상 차감량을 확인하고, 수정할 때마다 새로 비용이 드는지 알고 싶다. 음성 AI를 담지 않았거나 크레딧이 부족하면 안내 후 구성 변경을 결정한다. ‘쓴 만큼만’이라는 기대와 실제 월 구독·주간 소멸 정책의 차이는 사전에 설명해야 한다.

**필수 경험:** 대화 맥락 유지(C-1), 모델과 이유 표시(C-2), 예상 비용(C-3), 음성 재생·다운로드(C-6), 이미지 다운로드(C-7), 미선택 AI·부족 안내(C-8·C-9).

**검증 과제:** 대본의 금액을 바꾼 뒤 음성과 썸네일 요청에서 변경 내용이 유지되는지 관찰한다. 복사·재설명 횟수, 완료 시간, 재생성 이유를 기존 방식과 비교한다. 결과가 마음에 들지 않을 때 추가 차감에 동의하는지도 묻는다.

## P02 박서연 — 캠페인 마감을 관리하는 마케터

**배경:** 소규모 교육 브랜드에서 SNS 광고와 랜딩 문구를 담당한다는 가상 설정이다. Parquet의 마케팅 전문가 레코드에서 숏폼 기획·성과 분석·예산 정산이라는 직무 맥락을 참고했다.

**현재 흐름:** 글쓰기 AI에서 광고 카피를 만들고 이미지 도구에 브랜드 설명을 다시 입력하며 번역 도구로 해외용 문구를 다듬는다. 캠페인의 대상·금지 표현·말투가 도구마다 달라지는 것이 부담이다.

**해야 할 일:** 같은 프로모션의 인스타그램 문구 3종과 이미지 후보, 영문 문구를 담당자 검토에 올린다. 최종 게시와 광고 집행은 사람이 한다.

**Siempre 흐름:** 승인된 브랜드 설명과 행사 조건을 입력하고 Claude로 카피를 작성한다. Nano Banana로 시안을 받고, Qwen으로 번역을 요청한다. 지원 AI 선택과 라우팅은 PRD를 따른다.

**선택 기준과 막힘:** 브랜드 일관성과 반복 수정의 비용을 함께 본다. 민감한 고객 명단이나 미공개 실적을 프롬프트에 넣지 않으며, 이미지의 글자·행사 조건은 직접 검수한다. 팀 승인·협업 기능은 MVP에 없으므로 결과를 내려받아 기존 승인 절차에 전달한다.

**필수 경험:** 맥락 유지(C-1), 모델·차감 표시(C-2·C-3), 이미지 변형·다운로드(C-7), AI별 사용량(R-2).

**검증 과제:** 같은 캠페인의 타깃을 바꾼 뒤 카피·이미지·번역에 반영되는지 확인한다. 수정 횟수와 담당자 승인까지의 시간을 기록한다. “모델 선택을 맡기면 어느 단계에서 불안한가?”를 질문한다.

## P03 정민준 — 자료를 이해하고 발표를 준비하는 대학생

**배경:** 전공 과제와 팀 발표를 병행하며 무료 사용량을 먼저 확인하는 대학생이라는 PRD 기반 가설이다. Parquet 탐색에서 ‘대학생’ 단어가 있는 교수·검표원도 검색됐으므로 이를 학생 근거로 채택하지 않았다. 조사 엑셀의 학생 사례는 작업별 도구 분담을 이해하는 보조 자료다.

**현재 흐름:** 자료 탐색, 논문 이해, 요약, 발표 구성에 여러 도구를 사용한다. 도구 사이에서 원문과 요약의 연결이 끊기고 무료 한도에 막히는 문제가 있다.

**해야 할 일:** 읽은 자료의 핵심 주장과 한계를 이해하고 직접 확인한 참고문헌을 바탕으로 발표 개요를 만든다. AI가 만든 인용을 그대로 제출하지 않는다.

**Siempre 흐름:** Qwen·Mistral 등 최소 2개 AI를 무료 단계로 담고 직접 제공한 텍스트를 요약·번역한다. 긴 논문의 파일 첨부는 P1(C-11)이므로 초기 검증에서는 짧은 발췌문을 사용한다. 실시간 검색·출처 자동 검증·슬라이드 파일 생성은 PRD의 보장 기능이 아니다.

**선택 기준과 막힘:** 무료 한도와 추가 비용, 설명의 이해 가능성이 중요하다. 무료 사용량은 PRD의 미확정 제안값이다. 원문 근거가 없는 답변은 다시 확인하고 저작물 전체를 무단 업로드하지 않는다.

**필수 경험:** 시작 전 최소 AI 2개 안내(P-3), 무료 시작(B-3), 예상 차감(C-3), 사용량 확인(R-2), 더 꼼꼼하게(C-5).

**검증 과제:** 제공한 자료에서 주장·근거·한계를 구분하고, 틀린 요약을 발견했을 때 원문으로 돌아갈 수 있는지 본다. “무료 한도가 끝나면 어떤 작업에 비용을 낼 것인가?”를 묻는다.

## P04 이지훈 — 문서를 정리하는 중소기업 직장인

**배경:** 거래처 대응과 문서 정리를 맡는 33세 사무직이라는 설정이다. Parquet 경리 사무원 레코드의 단가표 관리·거래처 조율·퇴근 전 업무 완료 맥락을 참고했다. 실제 회계 판단을 AI에 맡기는 사용자는 아니다.

**현재 흐름:** 회의 메모를 보고서 초안으로 정리하고 다른 도구에서 거래처 메일을 번역한다. 항목 누락과 수치 변형을 다시 확인하는 데 시간이 든다.

**해야 할 일:** 익명화한 회의 메모에서 결정사항·담당자·기한을 뽑고 보고서와 후속 메일 초안을 만든다. 녹음 전사·자동 메일 전송은 포함하지 않는다.

**Siempre 흐름:** Claude로 보고서 초안을 만들고 Qwen으로 메일 번역을 이어간다. 회사 승인 범위 안의 자료만 사용하고 원문 수치와 이름을 대조한다.

**선택 기준과 막힘:** 문서 누락 방지와 예상 비용이 중요하다. 로그인·조직 권한·팀 요금제가 MVP 범위 밖이므로 회사 기밀 처리용 제품으로 가정하지 않는다. 실제 단가표 대신 가상 자료로 시연한다.

**필수 경험:** 맥락 유지(C-1), 모델 설명(C-2), 깊은 검토 선택(C-5), 크레딧 확인(R-2).

**검증 과제:** 결정사항 5개가 있는 가상 회의 메모로 누락·수치 변경을 확인한다. “어떤 자료까지 외부 AI에 넣을 수 있는가?”와 “수정 비용을 언제 확인하고 싶은가?”를 묻는다.

## P05 최수진 — 짧은 시간에 가게를 홍보하는 카페 운영자

**배경:** 매장 운영과 SNS 홍보를 혼자 맡는 42세 카페 사장이라는 PRD 기반 설정이다. 검색된 음식점 방문 취미 레코드를 자영업자 근거로 사용하지 않았다.

**현재 흐름:** 영업을 마친 뒤 홍보 글을 만들고 디자인 도구에서 포스터를 준비한다. 도구 학습 시간과 행사 날짜·가격을 다시 입력하는 번거로움이 크다.

**해야 할 일:** 신메뉴 소개 글, 포스터 후보, 리뷰 답글 초안을 준비한다. 메뉴 가격·알레르기 정보·영업시간은 사람이 정확히 확인한다.

**Siempre 흐름:** Mistral로 짧은 홍보 문구와 답글을 만들고 Nano Banana로 포스터 후보를 요청한다. 최종 인쇄용 편집·지도 등록·SNS 자동 게시는 기존 도구에서 진행한다.

**선택 기준과 막힘:** 적은 작업량에도 매월 고정비가 생기는지, 주간 미사용 크레딧이 소멸하는지 확인하려 한다. 모바일 폭에서 메뉴를 찾고 이미지를 내려받는 흐름도 검증한다.

**필수 경험:** 쉬운 구성 선택(P-1·P-2), 소멸 안내(P-5·R-3), 이미지 다운로드(C-7), 부족 안내(C-9).

**검증 과제:** 가격·기간이 있는 신메뉴 행사로 글과 이미지를 만들고 두 결과의 일치를 확인한다. “한 달에 몇 번 홍보물을 만드는가?”를 물어 구독 적합성을 검증한다.

## P06 한지우 — 고객 수정에 대응하는 프리랜서 디자이너

**배경:** 고객별 브랜드 카피와 시안을 준비하는 29세 프리랜서라는 설정이다. Parquet의 미디어 콘텐츠 디자이너 레코드에서 인쇄·웹 도구 활용과 독립 목표를 참고했지만, 원본 레코드는 재직 중이므로 프리랜서 상태는 새로 설정한 가설이다.

**현재 흐름:** 고객 브리프를 글쓰기 AI에 요약하고 이미지 도구에 시각 조건을 다시 입력한다. 수정 지시가 쌓일수록 이전 조건을 빠뜨리기 쉽다.

**해야 할 일:** 고객의 승인된 브리프로 문구와 이미지 방향 3개를 만들고, 선택한 방향의 수정안을 제시한다. 최종 편집·벡터화·인쇄 파일 제작은 전문 도구에서 한다.

**Siempre 흐름:** Claude로 브리프와 카피를 정리하고 Nano Banana로 시안을 만든다. 고객별 새 대화로 작업을 구분하되 프로젝트 권한 관리·대화 검색을 지원한다고 가정하지 않는다.

**선택 기준과 막힘:** 수정 비용, 결과물 다운로드, 원래 조건 유지가 중요하다. 고객의 자료 사용 허락을 확인하고 미공개 자료를 임의로 전송하지 않는다. 생성 결과의 상업 이용 가능성은 실제 공급사 조건과 계약에 따라 별도로 확인한다.

**필수 경험:** 맥락 유지(C-1), 다시 받기 추가 차감(C-4), 이미지 변형(C-7), AI별 사용량(R-2).

**검증 과제:** 고객 수정 지시 3개를 순차 입력해 이전 승인 조건이 유지되는지 본다. 다른 모델로 다시 받을 때 추가 차감을 이해했는지 확인한다.

## P07 윤태호 — 상품과 고객 응대를 관리하는 온라인 판매자

**배경:** 스마트스토어를 운영하며 해외 판매를 시험하려는 34세 판매자라는 설정이다. Parquet의 온라인 쇼핑 판매원 레코드에서 키워드 분석·고객 응대·내실 운영 맥락을 참고했다. 해외 판매 경험과 AI 사용은 추가 가설이다.

**현재 흐름:** 상품 설명을 작성하고 번역한 뒤 반복 문의 답변을 만든다. 규격·배송 조건·반품 설명이 언어마다 달라지면 고객 불만으로 이어진다.

**해야 할 일:** 직접 확인한 상품 규격과 정책을 기반으로 한국어 설명과 외국어 초안을 만들고 문의 답변을 준비한다. 상품 등록과 답변 전송은 사람이 한다.

**Siempre 흐름:** Qwen으로 설명 번역을, Mistral로 짧은 문의 답변을 요청한다. 상품마다 대화 맥락에 확정 규격을 제시한다. 실시간 재고 조회·쇼핑몰 연동·자동 고객 응대는 범위 밖이다.

**선택 기준과 막힘:** 번역의 숫자·단위 보존, 낮은 반복 작업 비용이 중요하다. 주문자의 이름·주소·연락처를 제거한 문의 예시를 사용한다. 제품 효능과 환불 조건은 AI가 새로 만들지 않도록 원문과 대조한다.

**필수 경험:** 번역 라우팅과 맥락(C-1), 예상 비용(C-3), 미선택 AI 안내(C-8), 크레딧 사용량(R-2).

**검증 과제:** 규격·배송·반품 조건이 있는 상품 설명을 번역하고 항목별 누락을 확인한다. “어떤 언어와 문의 유형에서 사람이 꼭 검수해야 하는가?”를 묻는다.

## 한국어 이름 적용 원칙

해외 공개 인물의 이름을 한국인 실명처럼 바꾸면 조사 출처가 왜곡된다. 따라서 원본 조사 엑셀은 그대로 두고, 위 가상 인물에 자연스러운 한국어 이름을 부여했다. Allison Abeldt의 학습 도구 분담은 P03, Alex Braun·Dheeraj Sharma의 제작 흐름은 P01, Andrea Linehan·Asmaa Abolyzeed·Ali Qureshi의 마케팅 작업 분담은 P02의 질문 설계에 참고할 수 있다. 이는 실명 번역이나 일대일 인물 복제가 아니며 원래 인물의 성과·소속·사용 도구를 가상 인물의 검증된 사실로 이전하지 않는다.

## 검증 계획

첫 인터뷰는 대표 시나리오의 P01부터 진행하고, P02·P06으로 작업 맥락 유지의 재현성을 확인한다. 참여자는 최근 실제 작업에서 AI를 2개 이상 사용한 경험을 설명할 수 있어야 한다. 직업만으로 다중 AI 사용자라고 단정하지 않는다.

공통으로 최근 작업 순서, 복사·붙여넣기 지점, 실제 결제 내역을 자발적으로 공유할 수 있는 범위에서 확인한다. 가상 자료로 사용성 과제를 수행하고 완료 여부·소요 시간·맥락 재설명·라우팅 수정·추가 차감 이해도를 기록한다. 인터뷰 결과는 가설별로 반영한다. PRD의 4주 재방문율·유료 전환율은 실제 베타에서 측정하며 이 문서로 달성했다고 주장하지 않는다.

PRD의 미확정 무료 사용량·텍스트 사용량 기간·차감량을 그대로 미확정으로 유지한다. 가상 페르소나의 예산을 실제 지불 의사로 사용하거나 출시 기능을 확대하는 근거로 삼지 않는다.
