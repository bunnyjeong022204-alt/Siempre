# backend

백엔드 담당자가 서버 코드를 올리는 폴더입니다.

## 여기에 올리는 것

- 서버 코드, 데이터베이스 구조(스키마), 테스트
- 환경 변수 예시 파일(`.env.example`). 값은 비워 두고 이름만 적어요.

## 만들 API (MVP 예정, `docs/PRD.md` 5장)

| 기능 | 내용 |
| --- | --- |
| 회원가입·로그인 | 이메일 가입, 로그인·로그아웃, 로그인 상태 확인 |
| 구독 | 장바구니 금액 계산, 데모 결제, 내 구독 조회 |
| 크레딧 | AI별 주간 크레딧 지급·차감, 남은 크레딧과 사용 기록 조회 |
| 대화 | 요청 분류 → 알맞은 AI 호출, 예상 크레딧, 다른 모델로 다시 받기 |

## 올리지 않는 것

- 실제 API 키·비밀번호가 든 `.env` 파일
- 데이터베이스 파일, 로그, `node_modules/` 등

코드를 올릴 때 실행 방법과 API 목록을 이 README 아래에 적어 주세요.
