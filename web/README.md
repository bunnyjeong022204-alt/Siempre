# Siempre MVP

한 대화창에 요청을 적으면 Claude, GPT, Gemini, 이미지 모델 중 알맞은 모델을 자동으로 골라 답하는 서비스의 MVP입니다.

## 실행

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
cd web
cp .env.example .env   # API 키를 넣으면 실제 모델 호출, 비워 두면 데모 응답
npm start              # http://localhost:3000
npm test               # 라우터·주간 크레딧 테스트
```

| 주소 | 화면 |
|---|---|
| `/` | 대화: 자동 라우팅, 답변별 모델·크레딧 표시, 다른 모델로 다시 받기, 보내기 전 예상 크레딧 |
| `/plans` | 요금제: 라이트·스탠다드·헤비, 주간 크레딧 |
| `/wallet` | 크레딧: 남은 크레딧, 다음 지급일, 사용 내역 |
| `/admin` | 관리자: 공급사 연결 상태, 지표, 라우팅 규칙 켜고 끄기, 데모 초기화 |

## 동작 방식

- **라우터** (`lib/router.js`): 요청을 가벼운 대화, 글쓰기, 요약·번역, 고난도, 이미지 중 하나로 분류합니다. 기본은 규칙 기반이고 `ROUTER_MODE=llm`이면 Claude Haiku로 분류합니다.
- **모델 선택** (`lib/config.js`의 `RULES`): 유형마다 기본 모델과 대체 모델이 있습니다. 기본 모델의 키가 없거나 호출이 실패하면 대체 모델로 넘어가고, 키가 하나도 없으면 데모 응답을 돌려줍니다.
- **크레딧** (`lib/store.js`): 한국 시간 월요일 0시에 요금제만큼 지급하고, 남은 크레딧은 이월하지 않습니다. 가벼운 대화는 0크레딧(하루 300회 한도), 글쓰기 5, 요약·번역 3, 고난도 19, 이미지 17크레딧입니다.
- **대화 맥락**: 모델이 바뀌어도 앞의 대화를 함께 보내서 이어집니다. 이미지 요청에는 마지막 요청만 보냅니다.

## MVP라서 아직 없는 것

- 회원가입과 로그인: 사용자 1명(데모)의 상태를 `data/state.json`에 저장합니다.
- 결제: 요금제 변경은 바로 적용되는 데모, 추가 충전은 안내만 띄웁니다.
- 대화 기록 저장, 파일 첨부, 음성 생성, 에이전트 작업

## 확인이 필요한 것

- `.env.example`의 모델 ID(특히 OpenAI, Gemini)는 각 공급사 문서에서 실제 값을 확인해 바꿔 주세요.
- 실제 서비스 전에 각 공급사 API 이용약관, 개인정보 국외 이전 동의, 선불 크레딧 환불 규정을 검토해야 합니다.
