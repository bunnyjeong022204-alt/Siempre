# INTENT — 예외 흐름: 박서연 · 마케터

> 기본 흐름이 아닌 상황에서도 사용자가 막히지 않고, 비용과 정보가 새지 않게 하려는 의도를 정리한다.
> 이 흐름을 MVP 대화 화면에서 보여 준다.

## 1. 왜 예외 흐름을 정하나
- 실제 작업은 중간에 조건이 바뀌고, 결과가 틀리고, 요청이 섞인다.
- 자동 라우팅이 이런 순간에 엉뚱한 모델을 쓰거나 앞 정보를 잊으면 신뢰가 깨진다.
- 예외 상황에서도 "왜 이 모델인지, 얼마가 드는지"를 먼저 보여 줘서 믿고 쓰게 한다.

## 2. 사용자
**박서연 · 마케터**
신학기 캠페인의 SNS 카피·이미지·영문 문구를 준비한다.
결과물은 사내 승인 절차로 넘긴다.

## 3. 기본 흐름
| 순서 | 사용자 요청 | 답하는 모델 | 화면에 보이는 것 |
| --- | --- | --- | --- |
| 1 | 브랜드 말투, 대상 고객, 행사 조건 입력 | — | 입력한 조건이 "작업 조건" 카드로 고정됨 |
| 2 | "인스타그램 광고 문구 3개 써줘" | Claude Sonnet | 모델 칩 · "글쓰기 요청이라 자동 선택" · 차감 크레딧 |
| 3 | "두 번째 문구로 캠페인 이미지 만들어줘" | Nano Banana | 이미지 카드 · 앞 문구와 조건이 함께 전달됨 |
| 4 | "이 문구를 해외 고객용 영어로 번역해줘" | Qwen Plus | 번역 결과 · "번역 요청이라 자동 선택" |
| 5 | 결과 내려받기 | — | 문구·이미지 내려받기 버튼 |

## 4. 예외 흐름
| 예외 | 의도 | 처리 흐름 | 화면에 보이는 것 |
| --- | --- | --- | --- |
| 대상을 대학생 → 학부모로 변경 | 바뀐 조건이 앞 결과물에도 반영되게 | 변경 조건 확인 → Claude로 카피 수정 → 기존 이미지·번역도 고칠지 선택 | "작업 조건" 카드 갱신 · "이미지·번역도 수정할까요?" 선택 버튼(각각 예상 크레딧 표시) |
| 이미지에 행사 날짜·가격이 틀림 | AI 이미지 속 글자 오류를 사용자가 바로 잡게 | 문구 확인 안내 → 이미지 재생성 또는 글자 없는 배경만 받고 외부 편집 도구에서 입력 | 이미지 카드 아래 "글자 확인 필요" 안내 · [다시 만들기] [배경만 받기] 버튼 |
| "카피 써줘"와 "전략 비교 분석해줘"가 섞임 | 한 요청에 비싼 모델을 통째로 쓰지 않게 | 카피 작성인지 전략 분석인지 먼저 확인 → 작성은 Sonnet, 깊은 분석은 Opus → 비용이 달라지면 실행 전 표시 | "어떤 걸 먼저 할까요?" 선택 카드 · 선택지마다 모델과 예상 크레딧 |

## 5. 지켜야 할 원칙
1. **단순 수정에 고난도 모델을 쓰지 않는다.** 문구 고치기는 Sonnet, 깊은 분석만 Opus.
2. **확정된 정보는 다음 AI에도 넘긴다.** 브랜드 말투, 대상, 행사 날짜·가격은 모델이 바뀌어도 그대로 전달한다.
3. **비용이 달라지면 실행 전에 보여 준다.** 사용자가 고른 뒤에만 크레딧을 쓴다.
4. **막지 말고 다음 행동을 제시한다.** 오류나 애매함이 생기면 선택 버튼으로 다음 길을 보여 준다.

## 6. MVP 화면에 보여 줄 것
- 대화 화면 안에서만 보여 준다. 새 화면은 만들지 않는다.
- 새로 필요한 화면 요소: 작업 조건 카드, 수정 범위 선택 버튼, 글자 확인 안내, 요청 확인 선택 카드
- 이미 있는 요소를 다시 쓴다: 모델 칩, 선택 이유, 예상 크레딧, 다른 모델로 다시 받기
