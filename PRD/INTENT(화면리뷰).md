# INTENT — 화면 리뷰 반영 (2026-11-09)

> 화면 리뷰에서 나온 수정 사항 7가지의 의도를 정리한다.
> 확정되면 PRD·SPEC·PLAN과 담당 문서에 반영한다.

## 한눈에 보기
| # | 무엇을 | 왜 | 담당 |
| --- | --- | --- | --- |
| 1 | 두 사람의 API를 하나로 합쳐 시연 | 백엔드가 둘로 나뉘어 시연할 때 서버가 두 개 필요함 | 권희수, 김형민 |

## 1. API 합치기 · 공유하기
**문제:** 회원가입 API(김형민)와 구독·대화·크레딧 API(권희수)를 따로 만들어서, 시연하려면 서버를 두 개 띄워야 한다.
**의도:** 시연과 프론트엔드에서는 **서버 하나, 주소 하나**로 보이게 한다.
**바꿀 것**
- 서버 시작 파일(`backend/shared`) 하나에 두 사람의 라우트를 등록한다. 각자 자기 줄만 고친다.
- 주소 규칙: `/api/auth/*`(김형민), `/api/subscription/*` · `/api/chat/*` · `/api/credits/*`(권희수)
- API 목록을 한 문서(`docs/api.md`)에 모아 프론트엔드와 공유한다.
- 시연 전날까지 두 사람 코드를 `main`에 합치고 한 번 같이 통으로 실행해 본다.
**완료 기준:** 서버 하나만 실행해서 가입 → 구독 → 대화 → 크레딧이 끝까지 된다.

## 2. 구독 할인 카드 중복 제거
**문제:** 묶음 할인 안내가 화면 두 곳에 같은 내용으로 보인다.
**의도:** 할인 정보는 한 곳에서만, 금액과 함께 보여 준다.
**바꿀 것:** 묶음 할인은 장바구니 요약에만 남긴다. 다른 쪽 카드는 지운다.
**완료 기준:** 구독 화면에 할인 정보가 한 번만 나온다.

## 3. 결제창 만들기
**문제:** 결제 수단을 고르는 화면이 없다.
**의도:** 실제 서비스처럼 결제 수단을 고르는 경험을 보여 준다. 실제 결제는 하지 않는다.
**바꿀 것**
- 결제창에 결제 내용(담은 AI, 할인, 결제액) + 결제 수단 선택: **네이버페이 / 신용·체크카드**
- 어느 쪽을 골라도 데모 결제로 처리하고, "실제로 결제되지 않아요"를 표시한다.
- 고른 결제 수단은 구독 정보에 저장해 크레딧 화면 "내 구독"에 보여 준다.
**완료 기준:** 결제 수단을 고르고 결제하면 구독이 시작된다.

## 4. 음성 기능은 광고에서 확실히
**문제:** 음성 생성은 MVP 범위 밖인데, 사용자에게 알리지 않으면 기대감을 놓친다.
**의도:** 서비스 화면에는 넣지 않고, 홍보 카드뉴스·홈 화면에서 "곧 출시"로 분명하게 보여 준다.
**바꿀 것:** 광고에 음성 기능 카드 추가 ("대본을 바로 음성으로, 곧 만나요"), 서비스 화면에서는 음성 관련 버튼·문구를 뺀다.
**완료 기준:** 광고를 본 사람이 "음성은 곧 나온다"를 알 수 있고, 서비스 안에서 음성 기능을 찾다가 막히지 않는다.

## 5. 입력창에서 모델 바꾸기
**문제:** 지금은 답을 받은 뒤 "다른 모델로 다시 받기"로만 모델을 바꿀 수 있다.
**의도:** 원하는 모델이 있으면 보내기 전에 고르게 한다. 기본값은 **자동**이다.
**바꿀 것**
- 입력창 옆에 모델 선택: [자동] + 담은 AI의 모델 목록 (모델마다 예상 크레딧)
- 고른 모델이 요청과 맞지 않으면 "모델 오류" INTENT의 안내를 띄운다.
- 한 번 보내면 다시 [자동]으로 돌아간다.
**완료 기준:** 모델을 직접 골라 보내면 그 모델이 답하고, 차감 크레딧이 그 모델 기준으로 나온다.

## 6. 가격 설정 이유 (두 문장)
> 각 단계 가격은 실제 API 원가에 운영 마진을 붙이되, 공식 구독(예: ChatGPT Plus 약 ₩29,000)보다 싸게 맞췄어요.
> 여러 AI를 묶을수록 5~10% 더 할인되고 남은 크레딧은 이월하지 않기 때문에, 사용자는 따로 구독할 때보다 덜 내고 우리는 낮은 가격을 유지할 수 있어요.

**완료 기준:** 팀원 누구나 이 두 문장으로 가격 질문에 답할 수 있고, PRD 3장에 같은 문장이 들어간다.

## 7. AI별 크레딧에 추가 충전
**문제:** 추가 충전 버튼이 전체 크레딧에 하나만 있는데, 크레딧은 AI마다 따로 담아서 쓴다.
**의도:** 모자란 AI의 크레딧만 골라서 채우게 한다.
**바꿀 것**
- 크레딧 화면: AI별 크레딧 카드마다 [추가 충전하기] 버튼. 전체 추가 충전 버튼은 없앤다.
- 대화 중 크레딧 부족 안내: 부족한 그 AI의 추가 충전으로 바로 연결.
- PRD 4-1, 5-4의 "추가 충전"을 "AI별 추가 충전"으로 고친다.
**완료 기준:** 크레딧이 부족한 AI만 충전되고, 다른 AI 크레딧은 그대로다.
