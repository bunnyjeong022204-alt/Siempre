# SPEC

## 완료 기준 (MVP)
아래 흐름을 한 사람이 처음부터 끝까지 막힘없이 할 수 있으면 완료다.
가입 → 로그인 → AI 담기 → 데모 결제 → 대화 → 크레딧 확인

## 화면별 완료 조건
| 화면 | 완료 조건 |
| --- | --- |
| 회원가입·로그인 | 이메일로 가입·로그인·로그아웃이 된다. 로그인 안 하면 다른 화면에 못 들어간다 |
| 구독 선택 | AI별 단계를 고르면 금액·할인·주간 크레딧이 바로 바뀐다. PRD 예시가 ₩23,670으로 나온다 |
| 데모 결제 | 결제하면 구독이 저장되고 이번 주 크레딧이 채워진다 |
| 대화 | 요청에 맞는 모델이 답하고, 모델 칩·이유·차감 크레딧이 보인다. 다른 모델로 다시 받을 수 있다 |
| 크레딧 | 남은 크레딧, 다음 충전일, 최근 기록이 보인다. 모자라면 안내가 뜬다 |

## 기술 완료 조건
- API 키가 프론트엔드·깃헙에 없다
- 비밀번호는 해시로만 저장된다
- 백엔드 파트별 체크리스트(backend/*/README.md)를 모두 통과한다

## 안 만드는 것
실제 결제, 소셜 로그인, 대화 검색, 설정, 팀 요금제, 모바일 앱
