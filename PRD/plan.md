# PLAN

## 역할
| 이름 | 맡은 것 |
| --- | --- |
| PM | 기술 스택·DB 결정, 화면 시안 확정, 일정 관리 |
| 권희수 | 홈페이지 전체 흐름. 구독·결제·대화·크레딧의 프론트엔드와 백엔드 |
| 김형민 | 회원가입·로그인의 프론트엔드와 백엔드 |

## 단계
| 단계 | 할 일 | 담당 | 끝나면 |
| --- | --- | --- | --- |
| 0. 준비 | 기술 스택·DB 결정, 공통 코드(shared) 올리기, 화면 시안 확정 | PM | 서버가 뜨고 빈 화면이 열린다 |
| 1. 가입·로그인 | 가입·로그인 화면 + auth API | 김형민 | 가입하고 로그인된다 |
| 2. 구독 | 장바구니·결제 화면 + subscription API | 권희수 | 결제하면 구독이 저장된다 |
| 3. 대화·크레딧 | 대화·크레딧 화면 + chat·credits API (처음엔 가짜 답변) | 권희수 | 가짜 답변으로 전체 흐름이 돈다 |
| 4. 실제 AI 연결 | 공급사 API 키 연결, 라우팅 다듬기 | 권희수, 김형민 | 실제 AI가 답한다 |
| 5. 합치고 점검 | 전체 흐름 테스트, SPEC 완료 기준 확인, 버그 수정 | 모두 | MVP 완료 |

- 2·3단계는 1단계와 동시에 시작한다. 권희수는 김형민의 로그인 기능이 끝나기 전까지 가짜 로그인 함수로 먼저 작업한다.
- 1단계가 끝나면 김형민이 "로그인한 사용자 확인" 함수를 권희수에게 넘기고, 둘이 함께 전체 흐름에 연결한다.
- 단계마다 PR 하나씩, main에 합치기 전에 상대방이 확인한다.
